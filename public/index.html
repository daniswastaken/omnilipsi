Direct media files download instantly via proxy. YouTube / TikTok / IG / X need an extractor backend — COBALT_API_URL.

    How it works: GET /api/info?url=… inspects the link (direct file → HEAD; page → OG/meta scrape; YouTube → oEmbed). GET /api/dl?url=… proxies the bytes with a proper download filename (fixes hotlink/CORS issues).

    Full “any site” support: YouTube + direct files + pages with video metadata work with zero setup. For TikTok / IG / X / JS-heavy obscure sites, deploy the bundled yt-dlp backend in ./extractor (one-click render.yaml / fly.toml, or any Docker host), then set EXTRACTOR_API_URL in wrangler.toml (+ npx wrangler secret put EXTRACTOR_TOKEN if set). Cobalt API instances also work via COBALT_API_URL.

    Local power mode: npm run dl -- "https://youtube.com/watch?v=…" uses yt-dlp on your machine.
